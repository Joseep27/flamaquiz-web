# FlamaQuiz web

Web estática oficial de FlamaQuiz, preparada para GitHub Pages y el dominio `flamaquiz.es`.

Incluye portada, soporte, términos de uso y política de privacidad.

## Publicación

En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch** y publica la rama `main` desde la carpeta raíz (`/`). El archivo `CNAME` configura el dominio personalizado.
